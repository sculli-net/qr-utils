Based on code from 
[soldair/node-qrcode](https://github.com/soldair/node-qrcode)

### Objectives
A simple vector based QR code generation library

Create QR Codes in JavaScript/TypeScript then render as
- SVG
- DOM elements
- PNG

Multiple render methods
- Individualised dots
- Smart shape / edge detection
- Negative space

Isolate components of the code by dot, row, column, corner or shape

Used for the "Learn QR" site from sculli.net
